title: Function Junction
---

## Learning Focus

Identify functions and describe relationships between inputs and outputs across representations.

## Big idea

A **function** assigns each allowable input exactly one output. You can see this in:

- graphs (vertical line test)
- tables (no repeated input with different outputs)
- equations (a rule that produces one value)

## Takeaways

- Ask: “For each $x$, is there exactly one $y$?”
- Features (intercepts, increasing/decreasing) live on top of that definition.
